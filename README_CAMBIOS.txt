CAMBIOS SOLICITADOS:
- QUITADO botón Fijar mi puesto (venta) -> puesto fijo en Chihuahua con Candela
- SOLO botón Mi ubicación (cliente)
- QUITADO QR de mi puesto
- DEJADO solo QR del cliente (pedido con folio)
- NUEVO QR para que cliente obtenga la app (se genera con la URL actual, puedes pegar tu URL final de GitHub Pages/Vercel y actualizar)

COMO USAR QR DE LA APP:
1. Sube a GitHub Pages o Vercel y obtén URL
2. En la app, en la sección "Descarga la App", pega tu URL en el input y dale Actualizar
3. Ese QR es el que imprimes en tu puesto: cliente escanea y descarga/instala la app

GENERAR APK:
- PWABuilder con tu URL de GitHub Pages
- o npm install + npx cap add android + npx cap open android
